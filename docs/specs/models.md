# Model specs (provisional)

The specs for each Model, gathered for the ticket [Gather verified specs for ACIER and CADRE](https://github.com/Kintukka2/FOSLN-WATCH/issues/16).

**Status: provisional.** Every figure comes from the Supplier's spec sheets, the Supplier's listings, or measurements taken from the sheet photos. None has been measured on a sample yet. Where the sources disagree, the figure is their average; the sources are listed under it. **TBC** marks a spec no source gives. The ticket [Verify the specs against the samples](https://github.com/Kintukka2/FOSLN-WATCH/issues/36) replaces every figure with a measured one.

Sources, in [`supplier-sheets/`](supplier-sheets/):

- **Sheet:** the Supplier's spec sheet ([ACIER](supplier-sheets/acier-chrome.png), [CADRE](supplier-sheets/cadre-black.png))
- **Listing:** the Supplier's marketplace listing ([ACIER](supplier-sheets/acier-listing.png), [CADRE](supplier-sheets/cadre-listing.png))
- **Photo:** measured from the sheet photo against the sheet's own case-length marker
- **Owner:** stated by the owner

The specs are assumed to be the same for both Dials of a Model. Only one Dial of each Model has a sheet.

## Rules for using these specs

- **The case material needs the Supplier's written confirmation**, ideally with the grade (304 or 316L), before any copy or spec table claims a "stainless steel case". Both listings say "Alloy". Until it's confirmed, say "stainless steel bracelet".
- **Never write "Hardlex".** It is Seiko's trademark. Write "hardened mineral crystal".
- **3 bar means splashes only.** The spec table and the care page say "not for swimming or showering".
- **CADRE's gold is a frame round the dial**, not the case. The copy says "gold frame" and never suggests a gold case. Don't write "gold-plated" until the finish is known.
- **Band length is not wrist range.** Show no wrist range until a sample is measured.

## Open flags

- **Battery:** both listings say "Battery included: no". Did the test orders arrive running?
- **ACIER case plate:** the sheet photo reads "FOSLN QUARTA WATCH", not QUARTZ. Check the stock.
